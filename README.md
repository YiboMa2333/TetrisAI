# Tetris AI Demo

This repository contains a gameplay demonstration of a Tetris autoplayer developed as part of my university coursework.

The project achieved the **2nd-highest score in the module, out of approximately 200 students**.

## Demo

[Watch the gameplay demo](demo.mp4)

## About the Project

The autoplayer evaluates possible block placements and selects moves automatically based on the current board state.

The original source code is not included in this public repository because the project was developed as assessed university coursework.

This repository is intended only as a portfolio demonstration of the completed project.
